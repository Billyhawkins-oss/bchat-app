Security notes

This console uses B CHAT's public Supabase key — the same one shipped in the app — so what it can read and delete is governed entirely by your database's Row Level Security policies. For production, restrict destructive access with RLS and consider moving admin writes (delete user, delete message) behind a server function that uses the service-role key. If a delete fails silently, RLS is blocking it — that's expected and safe.
